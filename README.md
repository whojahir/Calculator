# 🧮 Calculator Project (HTML, CSS & JavaScript)

# 📌 Description

This is a basic calculator web application built using HTML, CSS, and JavaScript.
The project focuses on understanding core JavaScript logic, DOM manipulation, and event handling without using built-in shortcuts like eval().
The calculator performs standard arithmetic operations such as addition, subtraction, multiplication, and division, similar to a real calculator.

# 🚀 Features

• ➕ Addition
<br>
• ➖ Subtraction
<br>
• ✖ Multiplication
<br>
• ➗ Division
<br>
• 🔢 Multi-digit number support
<br>
• 🧹 AC (All Clear) button
<br>
• ⌫ DEL (Delete last digit)
<br>
• 🔘 Decimal (.) support
<br>
• 📱 Responsive design

# 🛠️ Technologies Used

• HTML – structure of the calculator
<br>
• CSS – styling and layout
<br>
• JavaScript – calculator logic and button interactions

# 🧠 Concepts Practiced

• Selecting elements using querySelector & querySelectorAll.
<br>
• Handling button clicks with addEventListener.
<br>
• Managing application state using variables.
<br>
• Implementing arithmetic logic manually.
<br>
• Updating UI dynamically using DOM manipulation.
